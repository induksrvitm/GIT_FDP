Purpose
This repository stores academic documents used to improve the syllabus for the
course "Project Management with Git".

Repository Goal
Collaboratively review, improve and release a clearer version of the syllabus.

Files
- question-paper.docx: Question paper based on the current syllabus.
- syllabus-overview.pptx: Presentation overview of the syllabus.
- syllabus-improvement-notes.txt: Team notes on what should be improved.
- syllabus-experiment-plan.csv: Experiment-wise duration and improvement plan.
- rubrics.txt: Evaluation rubric for practical work.
- review-comments.txt: Peer review comments during Pull Requests.
- release-notes.txt: Notes for tagged syllabus versions.

Working Rules
1. Do not directly edit main for major changes.
2. Create a branch for each improvement area.
3. Use clear commit messages.
4. Use Pull Requests for review.
5. Tag only stable approved versions.

Example Branch Names
- feature-experiment-balance
- feature-assessment-rubric
- feature-github-workflow
- bugfix-learning-levels
